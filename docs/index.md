# Guide Windows 11 (24H2 → 26H2)

Bienvenue ! Ce guide s'adresse aux **utilisateurs débutants** qui souhaitent :

1. **Installer Windows 11** proprement, avec un **compte local** (sans compte Microsoft),
2. **Installer les pilotes** correctement,
3. **Optimiser** le système avec des outils reconnus (Chris Titus WinUtil, O&O ShutUp10++),
4. **Gérer et diagnostiquer** son PC au quotidien grâce à des commandes simples.

## Plan du guide

| Étape | Contenu |
|---|---|
| 🛠️ Installation | Préparation de la clé USB, installation avec compte local (toutes les méthodes), pilotes |
| ⚡ Optimisation | WinUtil de Chris Titus, O&O ShutUp10++ (mode recommandé, désactivation de l'IA) |
| 💡 Astuces | Diagnostic, mises à jour, commandes utiles au quotidien |

!!! info "Versions couvertes"
    Ce guide couvre Windows 11 de la version **24H2** jusqu'à **26H2**. Les méthodes d'installation avec compte local évoluant à chaque version, toutes les variantes connues sont détaillées.

!!! warning "Avant de commencer"
    - Sauvegardez vos données importantes avant toute installation.
    - Une connexion Internet est nécessaire pour télécharger les outils et mises à jour.
