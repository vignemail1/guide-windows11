# O&O ShutUp10++

**O&O ShutUp10++** est un petit utilitaire gratuit (portable, sans installation) de l'éditeur allemand O&O Software. Il centralise tous les réglages de confidentialité et de télémétrie de Windows 10/11 en une seule fenêtre.

## Installation et utilisation

1. Téléchargez-le sur le site officiel : <https://www.oo-software.com/fr/shutup10>
2. Lancez `OOSU10.exe` **en administrateur**.
3. **Créez un point de restauration** quand le logiciel le propose.

## Appliquer le mode recommandé ⭐

Menu **Actions** → choisissez :

> **« Appliquer uniquement les réglages recommandés »** *(vert)*

C'est le bon choix pour un débutant : il désactive la télémétrie, la publicité et le pistage **sans risque** pour le système (aucun réglage orange/rouge).

- 🟢 **Recommandé** : sûr, appliquez sans hésiter.
- 🟠 **Partiellement recommandé** : peut gêner certaines fonctions (ex. désactiver Windows Defender ou Windows Update) — à éviter pour un débutant.
- 🔴 **Non recommandé** : ne pas activer.

## Désactivation des fonctionnalités IA

Dans la liste (catégories *Windows Copilot*, *Cortana et assistant personnel*, *AI*) :

- ✅ Désactiver **Windows Copilot**
- ✅ Désactiver **Recall** / l'analyse IA locale si proposé
- ✅ Désactiver les **suggestions et contenus IA** dans la recherche
- ✅ Désactiver la personnalisation publicitaire (Advertising ID)

ShutUp10++ est mis à jour régulièrement pour couvrir les nouvelles options IA des versions 24H2 → 26H2.

## Bonnes pratiques

- Relancez ShutUp10++ **après chaque grosse mise à jour de Windows** : certaines options sont réactivées par Microsoft.
- Il peut s'exécuter en mode silencieux : `OOSU10.exe /quiet`.
